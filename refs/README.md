# refs/

Reading notes live in `notes/`, one file per paper, copied from `notes/_template.md`.
Paper PDFs go in `papers/` but are **git-ignored** (fetch them again from arXiv; the folder is kept via `.gitkeep`).

Rules: record the arXiv/DOI, what you actually read (abstract / full text / sections), what you would cite it for,
and what it does **not** show. Update `../docs/03-related-work.md` and `../docs/02-facts-register.md` when a status changes.
